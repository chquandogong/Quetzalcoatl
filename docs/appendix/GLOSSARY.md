# GLOSSARY — 용어집 (보충)

> 상태: 활성 · 날짜: 2026-07-03 · 소유자: Documentarian · 승인: CHENGHAO QUAN

**스킬 용어의 정본(SSOT)은 [SKILL.md §22 부록 A](../../skills/Quetzalcoatl/SKILL.md)다** — 스킬은 페이스트 단독으로 완결이어야 하므로 정의를 두 곳에 유지하지 않는다(v3.0.0 정리, 이중 유지 제거). 이 파일은 **부록 A에 없는 보조 용어만** 담는다.

| 용어                        | 뜻                                                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 승인된 계획 범위 내 자율    | 사람이 방향을 1회 승인한 뒤 그 범위 안에서만 자율 실행하는 모델(SKILL §1.7, D1).                               |
| 재개(Resume)                | 중단·레이트리밋 후 체크포인트부터 무손실로 이어가기(§19).                                                      |
| 작업 보드(claimable board)  | todo/doing/done/blocked + 소유자를 가진 작업 목록. 나눠·이어서 작업의 단위(§21.1).                             |
| live artifact               | claude.ai에 렌더되는 공유 가능 페이지. 핸드오프에서는 **읽기 미러**(§21.3).                                    |
| 모델 중립 강등              | 파일/git/artifact가 없는 환경에서 같은 규율을 마크다운 텍스트로 대체(§18.6 등).                                |
| 게이트 priors               | 모델이 학습으로 이미 갖춘, 파괴적 작업을 꺼리는 경향. 자율 절이 이를 대체하지 않음.                            |
| 프로젝트 브리핑(`/context`) | 프로젝트 현재 상태를 벤더-중립 1회성 읽기 스냅샷으로 합성해 새 모델·에이전트 환경을 온보딩(§24).               |
| 페이스트 번들(Paste Bundle) | `SKILL.md`(규칙) + `TEMPLATES.md`(양식) 합본 `dist/Quetzalcoatl-FULL.md`. 도구 없는 챗 환경의 설치물(v3.0.0~). |
