# FAQ

**Q. `/office-hours` 같은 모드가 슬래시 자동완성에 안 보여요.**
모드는 Claude Code에 등록된 별도 명령이 아니라 스킬 본문 §2의 약속이다. 자동완성에는 마스터(`/quetzalcoatl:Quetzalcoatl`)만 보인다. 스킬이 켜진 세션에서 `/dashboard`처럼 그냥 입력하면 전환되고, 정확히 쓰지 않아도 의도가 비슷하면 적용된다 — [모드](Modes).

**Q. GitHub에 새 버전이 올라갔는데 플러그인이 그대로예요.**
플러그인 캐시는 버전별 사본이다. `marketplace update` → 재설치(또는 `claude plugin update quetzalcoatl@quetzalcoatl`) → 세션 재시작. 마켓플레이스 클론이 오래되면 구버전이 다시 깔릴 수 있다 — [설치](Installation)의 조치.

**Q. ChatGPT에서도 쓸 수 있나요?**
모델 중립형이다. 도구 없는 챗 환경에서는 본문+양식 합본인 페이스트 번들 `dist/Quetzalcoatl-FULL.md`를 프로젝트 지침에 붙여넣는다. 파일·git·live artifact가 없는 환경에서는 같은 규율을 텍스트로 강등해 수행한다(§18.6 · §19.4 · §20.4 · §21.4).

**Q. "묻지 말고 끝까지"라고 했는데 중간에 멈췄어요.**
자율은 확인 질문을 줄이는 것이지 안전 게이트를 없애는 것이 아니다. 외부 발송·게시 · 결제 · 개인정보 · 삭제·강제 푸시 · 프로덕션 배포 · 공개 저장소 생성 · 비가역 변경은 유효한 승인 근거가 없으면 멈춘다. 사전에 허용목록(C-19)에 범위(대상·환경·행동·데이터·비용)를 적어 승인해 두면 멈추지 않는다 — [자율과 게이트](Autonomy-and-Gates).

**Q. 교차검증을 "실제로" 하려면요?**
다른 모델을 호출할 수단이 필요하다(예: 로컬 Codex CLI에 브리프를 넘기기). 수단이 없으면 스킬이 같은 모델 안에서 반박 관점을 시뮬레이션하고 "실제 교차검증 아님"을 표시한다. 라운드형으로 돌리면 예산·원장·종결 상태(합의/쟁점 잔존/검토 미완료)를 기록한다 — [교차검증](Cross-Validation).

**Q. 검증표는 언제 만드나요? 작은 일에도?**
프로젝트성 작업에만 `VERIFY.md`로. 간단·중간 작업은 별도 파일 없이 절차·결과·근거를 짧게 남기고, 작은 프로젝트는 테스트 계획 안의 한 절로 충분하다. 계획만 요청받았거나 실행 조건이 없으면 미실행 사유를 적는다 — [검증표](Verification-Map).

**Q. 사용자 선호와 다른 답을 추천해도 되나요?**
선호는 강한 기본값이다. 선호안을 후보에 넣어 같은 기준표로 비교하고, 명시적·실질적 우위가 있을 때만 투명하게 뒤집으며 근소하면 선호를 유지한다. 유지할 때도 가장 강한 반론을 함께 보인다 — [워크플로우](Workflow) §4.2.

**Q. 왜 본문에 특정 도구 이름이 없나요?**
본문은 모델·도구 중립이다(R13). 구체 도구·버전·기능명은 `docs/appendix/CAPABILITY_MATRIX.md`에만 둔다. 본문과 표가 갈리면 본문(중립 패턴)이 기준이다.

**Q. 이 위키를 고치려면요?**
위키는 저장소 `wiki/`의 파생 뷰다. 손으로 쓰는 페이지는 `wiki/*.md`를 고치고, 생성 페이지(모드·템플릿·용어집·릴리스 이력)는 정본(`SKILL.md`·`TEMPLATES.md`·`CHANGELOG.md`)을 고친 뒤 `python3 scripts/build-wiki.py`로 다시 만든다. 발행은 `scripts/publish-wiki.sh`.

**Q. 보안 문제를 발견했어요.**
게이트를 우회·약화시키는 문구, 프롬프트 인젝션으로 게이트·교차검증을 무력화하는 경로 등은 공개 이슈 전에 비공개로 — [`SECURITY.md`](https://github.com/chquandogong/Quetzalcoatl/blob/main/SECURITY.md).
